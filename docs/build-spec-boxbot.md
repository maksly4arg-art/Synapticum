## 3. UX-канон (правки Максима 22.07 - НЕ ломать)
1. **Минимум текста.** Приветствие = 1 строка. Без позиционирования (оно в канале слайдами/хештегами), без прайса (живёт в канале, меняется). Интро-экраны - 1-2 предложения максимум.
2. **UX «страниц», не полотно.** Кнопочный тап РЕДАКТИРУЕТ тапнутое сообщение (editMessageText) - меню перелистывается на месте. Новое сообщение - ТОЛЬКО после текстового ответа юзера и на /start. Тосты (answerCallbackQuery) вместо служебных сообщений.
3. **Вечноживые кнопки.** Тап по кнопке ЛЮБОГО старого сообщения работает всегда: jumpTo проваливает в тот шаг (стек обрезается/дополняется, ответы целы). Мёртвых кнопок не существует.
4. **«← Назад» везде** без потери введённого (стек шагов, ответы в сессии).
5. **Дизайн кнопок:** ВСЕ синие (`style: "primary"`, Bot API 9.4+); CTA-кнопки КАПСОМ (шрифт кнопок фиксированный - «крупнее» дают заглавные); эмодзи ТОЛЬКО в отображении, в ответы/лог пишется чистый label (ветвление и счётчик сравнивают строки!).
6. Тап «НАЧАТЬ» у бота убрать НЕЛЬЗЯ (платформа, проверено 22.07). Путь без него - только Mini App (идея на потом, вместе с полным CSS-дизайном).

## 4. Данные и статусы
- Каждый ответ логируется; заявка = applications + answers (полный лог, при перебросе Б→А уходит и лог Б) + files.
- Статусы: `new → qualified → contacted → paid/client`. Переходы ТОЛЬКО руками Максима (/status) - квалификация ≠ верификация, защита у денег (предоплата), не на входе.
- Сессии персистятся на каждом изменении - рестарты безопасны.
- Deep-link `?start=<payload>` = атрибуция (entry заявки) И точка входа:
  - `consult` / `self` → СРАЗУ воронка Б (первый вопрос, минуя меню) - для ссылки «Консультация» в закрепе
  - `order` / `forme` → сразу воронка А
  - `post` (кнопка под постами) / `pin` (закреп) / прочее → главное меню
  - ⚠️ Хештег ссылкой сделать нельзя (тап по #хештегу = поиск по каналу, платформа); в закрепе слово делается обычной гиперссылкой на deep-link.

## 6. Формат канала «CTA-слайд с кнопкой»
Канон в [[synapticum-slides-canon]] (секция в конце). Публикация: `npm run post -- --image <png>` из BoxBot ИЛИ бот Евы (админ канала). Это ОДИН ИЗ форматов канала, ~раз в 3 месяца, не под пруфами.
